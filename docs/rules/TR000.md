# TR000: TypeRules configuration is invalid

| | |
|---|---|
| Category | Configuration |
| Default severity | Warning |
| Code fix | No |

## Cause

A `typerules.*` key in `.editorconfig` or `.globalconfig` couldn't be applied:

- the key isn't in the form `typerules.<rule set>.<option>`, or the rule-set name contains
  characters other than letters, digits, `_` and `-`
- the option is unknown (e.g. a typo such as `require_seald`)
- a value is invalid: `max_accessibility` or `max_setter_accessibility` isn't a C#
  accessibility, or a boolean option isn't `true`/`false`
- the rule set has no `match`, or sets none of `max_accessibility`, `require_sealed`,
  `companion_interface`, `max_setter_accessibility`, `readonly_collections` and
  `namespace_pattern`
- the rule set sets `allow_init` without `max_setter_accessibility`
- a `namespace_pattern` alternative isn't dot-separated names, `*` and `**` (e.g. `App..Orders`,
  `App.Or*`)
- the rule set sets `companion_interface`, but a `match` type is a class rather than an interface
  (a companion interface can only extend interfaces)
- a `match` entry isn't a type ID (`M:...`, `P:...`), names a type that doesn't exist in a
  namespace that does, or names a type nothing can inherit from (a sealed or static class, a
  struct, an enum)

## Behavior

A rule set with any of these problems is ignored entirely, so a typo never leaves it
half-applied. Each distinct problem is reported once per project.

A `match` type whose namespace doesn't exist in the project is **not** reported. One
`.editorconfig` usually covers several projects, and most of them don't reference every type a
rule set names. That type is skipped in those projects, and the rule set still applies through
its other entries.

TR000 has no source location, because it's about configuration rather than code. It appears in
build output and the Error List, not on a line in the editor.

## Example

```ini
[*.cs]
# Typo in the type name: reported, because namespace MyApp exists.
typerules.endpoints.match = T:MyApp.IEndpont
# Typo in the option name.
typerules.endpoints.require_seald = true
```

```
warning TR000: Invalid TypeRules configuration: unknown option 'require_seald' in rule set 'endpoints' (known options: match, max_accessibility, require_sealed, companion_interface, max_setter_accessibility, allow_init, readonly_collections, namespace_pattern)
warning TR000: Invalid TypeRules configuration: rule set 'endpoints' matches type 'T:MyApp.IEndpont', which was not found
```
