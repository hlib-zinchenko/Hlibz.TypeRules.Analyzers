# TR001: Type is more accessible than its rule set allows

| | |
|---|---|
| Category | Design |
| Default severity | Warning |
| Code fix | Yes |

## Cause

A class, struct or record that inherits from or implements a rule set's `match` types can be
seen from more places than the rule set's `max_accessibility` allows.

## Configuration

```ini
[*.cs]
typerules.endpoints.match = T:MyApp.IEndpoint
typerules.endpoints.max_accessibility = internal
```

`max_accessibility` takes `public`, `protected_internal`, `internal`, `protected`,
`private_protected` or `private`. The two-word levels may also be written with a space
(`protected internal`).

## How it's checked

TR001 compares **effective** accessibility: the type's own modifier narrowed by every type it's
nested in. A `public` class nested in an `internal` class is internal, so it passes an `internal`
maximum.

`protected` and `internal` each allow access the other doesn't (derived types in other assemblies
vs. any code in this assembly), so neither fits within the other: a `protected` nested type
violates `max_accessibility = internal`, and an `internal` one violates
`max_accessibility = protected`. Only `private protected` fits within both.

Abstract types are checked too. `file`-local types always pass.

When a type matches several rule sets, the message names the ones it violates, and the maximum
shown is the strictest of all its rule sets, since that's what it has to meet.

## Example

```csharp
public sealed class GetUsersEndpoint : IEndpoint { }   // TR001
```

```
warning TR001: 'GetUsersEndpoint' is public, but rule set 'endpoints' allows at most internal
```

## Code fix

**Make '...' internal** sets the declared accessibility to the most permissive level that fits
the maximum and is legal where the type is declared. For example, `protected` isn't legal inside
a struct, so a type nested in one gets `internal` under a `protected_internal` maximum. Every
partial part that states an accessibility is rewritten; if none does, the first part gets one.

No fix is offered when no legal level fits, e.g. a top-level type under
`max_accessibility = private`.
